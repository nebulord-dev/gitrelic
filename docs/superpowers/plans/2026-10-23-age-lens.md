# Age lens (RELIC-374) Implementation Plan

> Executed inline in the session that wrote it; tasks name files, behavior and tests, and the code lands in the commits. Spec: `docs/atlas-views.md` › *Code Health › Age*. Core data shipped in #162.

**Goal:** Atlas's Age lens: Strata (primary) and Warm and cold (alternate), a Tests switch, the lens card, the table, the dormant-package badge, Stale Files merged away, docs.

**Architecture:** One scene data module (`age/strata.ts`) turns `ageMap` + `loc` + `fileClasses` into package rows of files with bands, memoised per report and tests flag. Two layouts draw it; `views/age.ts` adds findings and the table; Atlas gets `AgeCard`. No new theme tokens: bands are `{ mix: ['--cell-base', '--person'], t }`, the accent marks orphaned files and dormant packages (`atlas-label--hot` sub-lines).

**Mirrored constants (keep in step with core `analyzers/age-map.ts`):** `COLD_DAYS = 365`; band edges 90 / 365 / 730 / 1460 days.

---

### Task 1: `age/strata.ts` (data)

- `AGE_BANDS` (edges + names: Under 3 months, 3–12 months, 1–2 years, 2–4 years, 4+ years), `bandOf(days)`, `COLD_DAYS`.
- `AgeFile { file, ageInDays, band, lines, test, orphaned, orphanedAuthors, wokeAfterDays }`; `AgeRow { dir, files (oldest first), lines[5] by band, warm, cold, orphaned (lines), orphanedFiles, coldFiles, newestSource, dormant }`.
- `ageStrata(report, { tests })`: `ageMap.files` by `report.fileClasses` (source always; tests when asked; fixtures and generated never), lines from `loc.files`, grouped by `packageOf`, rows ordered most cold lines first, then most lines. `dormant` from core's `dormantPackages`. `ageStrataOf` memoises per report and flag.
- `ageSummaryOf(report)` (source files only): lines, cold lines and files, median cold file lines, oldest file, dormant packages, orphaned files and lines by package, woken files (longest gap first), fixture + generated count, `source`.
- Tests (synthetic report): banding at the edges, fixtures out and tests toggled, rows ordering, dormant flag from core, orphaned sums, summary numbers, an empty report.

### Task 2: Strata layout (`layouts/strata.ts`)

- Like the Churn swarm: one row per package (up to `STRATA_ROWS` = 14, the rest counted), row = `dir:` mark (`repo` for the root), files as `file:` dots by `jitter`, x = √(age / maxAge), ticks 3 mo / 1 / 2 / 4 / 8 / 16 yr within range, "now" at the left, a shaded cold zone from 1 yr, dot radius by lines, paint by band.
- Orphaned: an accent `ring` mark (`orphan:<file>`, `selects` the file) around the dot.
- Dormant row: name's sub-line "dormant · 3.4 years" with `atlas-label--hot`, row tinted toward the accent.
- Tests switch: a `card` mark with `toggles: AGE_TESTS` ("Tests: shown / hidden"), reading `input.open`.
- Tooltips: file (path, last changed N ago, lines, test, orphaned by whom, woke after N); row (cold / warm lines, files, newest source change, dormant).
- Tests: `checkScene`, a dot per drawn file, older to the right, orphan ring selects its file, dormant sub-line, the toggle mark and tests appearing only when open, the row cap.

### Task 3: Warm and cold layout (`layouts/warmCold.ts`)

- Same rows; the row's `dir:` mark spans its bar; band parts `age-part:<dir>:<band>` (select the package) left of the axis for the two warm bands, right for the three cold, oldest outermost; orphaned part in the accent at the far right, half height; names left, "25k cold · 1.4k orphaned" or "dormant · 3.4 years" (`atlas-label--hot`) right; heading with the cold share; the Tests switch.
- Tests: `checkScene`, warm left / cold right of the axis, lengths to scale, orphan part, dormant label, empty report.

### Task 4: View, findings, table, registration

- `views/age.ts`: `ageView` (`id: 'age-map'`), captions, `ageFindings` (cold; dormant, warning; orphaned, warning; woken; window-only fallback, warning; left-out fixtures), `ageTable` (source and tests: file, last change in days, lines, band, orphaned, kind, package; tier from band: under a year 0, 1–2 y 1, 2–4 y 2, 4+ y 3; oldest first).
- `views/index.ts` registers it; scene `index.ts` exports what Atlas needs.
- Catalog: drop `dead-code`; `age-map` becomes `Age`, `atlas: true`, new `explain`, moved after `cursed-files`. `catalog.test` count 22 → 21. Classic's `catalogParity.test.ts`: `ATLAS_MERGES['dead-code'] = 'age-map'`, `ATLAS_RENAMES['age-map'] = 'Age'`.
- Badge rule: `age-map`, dormant packages, fires at one. Badge comment about Stale Files goes.
- Overview: `readings` (`N dormant` or `N% cold`), `topEntities` (dormant packages, then orphaned files, oldest first); `dead-code` entries go.
- `fileFacts`: the Age row reads "3.4 years ago", warning tier and "· orphaned" when orphaned, "· woke after 8.4 years" when woken; the Stale row goes (its lens no longer exists).
- Tests: view test (layouts, findings on synthetic data, table tiers), catalog, badge, readings, fileFacts.
